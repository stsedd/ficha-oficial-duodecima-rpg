# Ficha da Duodécima — v5.11

Ficha oficial da Legio XII Fulminata integrada ao **Duodécima Core schema v2**.

A v5.11 mantém a mescla consolidada na v5.10: mecânicas atuais do Core v2 com a linguagem visual aprovada da v5.9.6 para temas, Fogo/Neve e baralho. Esta revisão faz o pente-fino de layout, texto e responsividade solicitado para habilidades, perícias, temas e cartas.

## Aparência

O tema é composto por **Modo + Paleta + Especial**. Dark e Light continuam independentes da cor escolhida. As paletas históricas permanecem disponíveis, incluindo as opções pastéis, e os especiais Fogo e Neve continuam separados.

O banner no topo é exclusivamente a imagem escolhida pelo usuário. O upload abre um editor de recorte com posição horizontal, vertical e zoom antes de salvar.

## Core

Quando online, as regras compartilhadas vêm de `https://stsedd.github.io/duodecima-core/`. O snapshot local funciona como fallback. A ficha entende múltiplos recursos, trackers por alvo, escolhas persistentes/progressivas, recursos locais de habilidade e efeitos estruturados de perícia.

## Publicação

O ZIP é **root-ready** para GitHub Pages. Substitua os arquivos da raiz do repositório pelo conteúdo do pacote. Os arquivos principais usam nomes `v511` e cache-buster `5.11.0` para reduzir risco de mistura com CSS/JS de versões anteriores.

Consulte `CHANGELOG_V5_11.md`, `VALIDATION_V5_11.md` e `CORE-INTEGRATION.md`.
